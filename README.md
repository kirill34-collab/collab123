```markdown
# Риэлтор-бот — Telegram-бот для поиска и размещения недвижимости

Простой Telegram-бот для рынка недвижимости. Пользователи могут просматривать объявления о покупке или аренде жилья, создавать собственные объявления и управлять ими. Все объявления проходят модерацию через статус "активно/неактивно".

## Что умеет бот

🏠 **Просмотр каталога** – объявления разделены по категориям:
  - 🏠 Покупка
  - 🏨 Аренда посуточно
  - 🏘️ Аренда надолго

📝 **Создание объявления** – пошаговый процесс с указанием:
  - Типа услуги
  - Описания объекта (комнаты, площадь, этаж, состояние)
  - Цены в рублях
  - Местоположения
  - Контактной информации

📋 **Управление объявлениями** – просмотр, активация/деактивация, удаление своих объявлений через команду `/My_ads`

📞 **Связь с продавцом** – просмотр контактной информации по каждому объявлению

⚠️ **Жалобы** – возможность пожаловаться на риэлтора, объект или работу бота

💡 **Предложения** – обратная связь с администратором

👤 **Автоматическая регистрация** – пользователи сохраняются в базе данных при первом запуске

## Стек технологий

- Python 3.11+
- aiogram 3 – фреймворк для Telegram Bot API
- SQLite – встроенная база данных (один файл)
- asyncio – асинхронное выполнение

## Структура проекта

```
realtor_bot/
├── main.py              # точка входа, запуск бота
├── bot.py               # вся логика бота (в текущей версии)
├── README.md            # этот файл
└── bot.db               # база данных SQLite (создаётся автоматически)
```

> **Примечание**: В текущей версии весь код находится в одном файле `bot.py`. При необходимости вы можете разделить его на модули (`handlers/`, `database.py`, `keyboards.py` и т.д.) для лучшей организации.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd realtor-bot
```

### 2. Настройка токена

Откройте файл `bot.py` и вставьте ваш токен в переменную `TOKEN`:

```python
TOKEN = "ваш_токен_бота"
```

### 3. Установка зависимостей

```bash
pip install aiogram
```

### 4. Инициализация базы данных

База данных `bot.db` создаётся автоматически при первом запуске. Будут созданы две таблицы:
- `users` – информация о пользователях
- `properties` – объявления о недвижимости

### 5. Запуск бота

```bash
python bot.py
```

## Как пользоваться ботом

### Для обычного пользователя

1. Откройте бота и нажмите `/start`
2. Бот автоматически зарегистрирует вас в системе
3. Появится главное меню с кнопками:
   - **📋 Каталог** – просмотр объявлений по категориям
   - **⚠️ Жалоба** – отправка жалобы
   - **💡 Предложения** – обратная связь

### Создание объявления

1. Нажмите `/add_ad` или кнопку "➕ Создать объявление" в каталоге
2. Выберите тип услуги:
   - 🏠 Купить
   - 🏨 Снять посуточно
   - 🏘️ Снять надолго
3. Введите описание объекта (комнаты, площадь, этаж, состояние и т.д.)
4. Укажите цену в рублях (только цифры)
5. Введите адрес объекта
6. Укажите контактные данные (телефон или другие способы связи)

После успешного создания вы получите ID объявления и сможете управлять им через `/My_ads`.

### Управление объявлениями

Команда `/My_ads` позволяет:
- ✅ **Активировать** – сделать объявление видимым в каталоге
- ❌ **Деактивировать** – скрыть объявление из каталога
- 🗑️ **Удалить** – деактивировать и скрыть объявление

### Просмотр каталога

1. Нажмите кнопку "📋 Каталог"
2. Выберите нужную категорию
3. Просматривайте объявления с возможностью:
   - Увидеть контакт продавца
   - Перейти к следующему объявлению
   - Вернуться в каталог

## Структура базы данных

### Таблица `users`

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PRIMARY KEY | ID пользователя в Telegram |
| username | TEXT | Имя пользователя |
| full_name | TEXT | Полное имя |
| join_date | TIMESTAMP | Дата регистрации |

### Таблица `properties`

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER PRIMARY KEY | ID объявления |
| user_id | INTEGER | ID пользователя (внешний ключ) |
| type | TEXT | Тип (buy/rent_daily/rent_long) |
| status | TEXT | Статус (active/inactive) |
| description | TEXT | Описание объекта |
| contact | TEXT | Контактная информация |
| location | TEXT | Адрес объекта |
| price | TEXT | Цена |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |

## Функционал по модулям

| Модуль | Описание |
|--------|----------|
| **init_db()** | Создание таблиц в базе данных при первом запуске |
| **add_user()** | Добавление нового пользователя или проверка существующего |
| **add_property()** | Создание нового объявления в базе данных |
| **get_properties_by_type()** | Получение всех активных объявлений по категории |
| **get_property_by_id()** | Получение информации об объявлении по ID |
| **update_property_status()** | Изменение статуса объявления (active/inactive) |
| **command_start_handler** | Приветствие и регистрация пользователя |
| **command_add_ad_handler** | Запуск процесса создания объявления |
| **command_my_ads_handler** | Отображение всех объявлений пользователя |
| **handle_text_messages** | Обработка текстовых сообщений в процессе создания объявления |
| **catalog_handler** | Отображение каталога категорий |
| **view_properties_handler** | Показ объявлений выбранной категории |
| **complaint_handler** | Форма отправки жалобы |
| **suggestions_handler** | Форма отправки предложений |

## Команды бота

### Основные команды

- `/start` – Начало работы, регистрация, главное меню
- `/add_ad` – Создание нового объявления (пошаговый процесс)
- `/My_ads` – Просмотр и управление своими объявлениями
- `/Contact` – Контактная информация администратора
- `/cancel` – Отмена текущего процесса создания объявления

### Inline-кнопки

- **📋 Каталог** – Просмотр категорий объявлений
- **⚠️ Жалоба** – Отправка жалобы на риэлтора, объект или бота
- **💡 Предложения** – Отправка предложений по улучшению
- **➕ Создать объявление** – Быстрый доступ к созданию
- **📞 Связаться с продавцом** – Просмотр контакта по объявлению
